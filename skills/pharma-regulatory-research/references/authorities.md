## Common reliance and harmonization mechanisms

Check whether the target country participates in any of these — they drive Section 3 (Reliance &
Reference Approval Acceptance).

| Mechanism | Relevance |
|-----------|-----------|
| **WHO Collaborative Registration Procedure (CRP)** | Faster national registration for WHO-prequalified or SRA-approved products in participating countries |
| **WHO-Listed Authorities (WLA) / former SRA list** | Many countries grant abridged review to products approved by these regulators |
| **WHO Global Benchmarking Tool (GBT) maturity level** | ML3/ML4 regulators typically run full reviews; lower-maturity regulators rely more on reference approvals |
| **ICH membership / observer status** | Determines whether ICH CTD format and guidelines are mandatory |
| **PIC/S membership** | May allow GMP inspection waivers based on PIC/S-member inspection reports |
| **GCC Centralized Registration** | Shared GCC procedure alongside national routes for UAE, Saudi Arabia, Kuwait, Qatar, Bahrain, Oman |
| **Access Consortium** | UK, Canada, Australia, Switzerland, Singapore work-sharing |
| **Project Orbis** | FDA-led concurrent oncology review with partner regulators |
| **EU-M4all (Article 58)** | EMA opinions for medicines intended for markets outside the EU |
| **ASEAN (ACTD)** | ASEAN Common Technical Dossier format |
| **African Medicines Agency / AVAREF / ZAZIBONA / EAC-MRH** | African regional joint assessment and reliance procedures |
